# job-hunter-skill
Universal job search automation skill for Claude

Скилл:
1. Проверяет резюме на изменения
2. Ищет вакансии на всех платформах
3. Фильтрует и ранжирует
4. Спрашивает подтверждение перед откликами
5. Отправляет отклики с уникальными письмами
6. Создаёт отчёт-артефакт с прямыми ссылками

---

## Ограничения

- Авто-отклики работают только там, где есть браузерный интерфейс (hh.ru, LinkedIn и др.)
- Вакансии с тестовым заданием — в отдельный список, без авто-отклика
- Telegram-поиск требует активной сессии в web.telegram.org
- Скилл не хранит пароли и не запрашивает API-ключи
